# CANADÁ PARA TODOS 🍁

Blog turístico de ejemplo hecho con HTML, CSS y JavaScript puro.

## Cómo abrirlo
1. Descomprime el ZIP.
2. Abre la carpeta `CANADA_PARA_TODOS`.
3. Haz doble clic en `index.html`. Se abrirá en tu navegador.
4. Necesitarás internet para cargar las fotografías y la tipografía externa.

## Incluye
- Diseño adaptable a computadora, tableta y teléfono.
- Colores rojo canadiense desvanecido, blanco y rosa suave.
- Destinos turísticos, galería, consejos y enlaces oficiales.
- Buscador y filtros de ciudades/naturaleza.
- No requiere instalar programas.

## Información y fotografías
Esta primera versión es estática; sus descripciones no son datos en tiempo real. Verifica precios, horarios, cierres, permisos, clima y accesibilidad en los sitios oficiales antes de viajar. Las imágenes se cargan desde Unsplash; revisa las condiciones aplicables antes de publicar el sitio. Para actualizaciones automáticas hará falta integrar una fuente de datos confiable.
